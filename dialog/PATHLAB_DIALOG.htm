Model

StructureIncluded paths

With no mediators, choose a moderator for the direct X to Y path. Covariates enter every mediator and outcome equation. Parallel and serial allow up to ten mediators. Combined allows up to six because its number of indirect routes grows rapidly. Additional rank, route, output-size and computation budgets still apply.

Put categorical X, moderators or covariates in the main Categorical variables (optional) box, then choose the reference rule under Model…. Indicator coding uses the lowest numerical or first alphabetical observed value when “first” is selected; “last” uses the highest or last value. References are resolved once on the common analysis sample and remain fixed during resampling. Labels do not replace underlying category values.

Moderators and stages

Assign up to three moderator variables in the main W, Z and Q boxes. Under Moderators…, choose None, W, Z, Q or a joint pair for each stage. Every assigned moderator must be used. First stage applies to all X-to-mediator paths; final stage to all mediator-to-Y paths; serial stage to included mediator-to-mediator paths; direct applies to X-to-Y. A joint pair adds the three-way product and every required lower-order term. A stage absent from the model or an unassigned moderator produces an actionable error.

Interaction and Johnson–Neyman diagrams

Open Diagrams…. Show both diagrams (recommended) is the default. Choose interaction only, Johnson–Neyman only, or tables only if preferred. Diagrams appear in the SPSS Viewer. Use the optional folder browser to retain PNG copies.

DiagramWhat to read
InteractionFitted outcome across the predictor, with a line for each moderator probe or category. Bands are pointwise confidence intervals for fitted means, not individual predictions. Binary-outcome fitted means use the probability scale.
Johnson–NeymanThe slope of a particular path across a continuous moderator. Read its interval against zero and the analytic boundaries within the observed moderator range. For logistic equations this is a log-odds path slope.

Other moderators are fixed at the conditions shown in each panel. All included paths and conditions are retained, with four panels per image when pagination is needed. A categorical X has separate reference contrasts where applicable. A continuous Johnson–Neyman region is inapplicable for a categorical moderator. A pure mediation model has no interaction to plot. The output explains inapplicability rather than manufacturing a diagram.

Johnson–Neyman diagrams describe conditional path slopes. A grid of bootstrap indirect-effect intervals is not an exact Johnson–Neyman region for an indirect effect. All displayed intervals are pointwise.

Inference

The default is 5,000 paired whole-case bootstrap samples, a 95% confidence level and HC3 coefficient covariance. Percentile bootstrap intervals are used for indirect effects and contrasts. The seed makes resampling reproducible. Moderator percentiles are fixed before resampling. With three numerical moderators, 16th and 84th percentiles give eight joint conditions; with at most two, the 16th, 50th and 84th percentiles are used.

All equations use one common complete-case sample, including SPSS user-missing and system-missing definitions and active filtering. Weights and split files are unsupported and must be disabled explicitly. The analysis does not change your dataset, center variables, construct scores, or impute missing observations.

Read results

Under Options…, Standard results begin with the model overview, fitted equations, main effects and requested diagrams. Choose Full to add detailed contrasts and diagnostic tables. The optional complete results file preserves the full numerical output. Review the common sample, equations, conditional direct/specific indirect/summed indirect/total effects, applicable indices or derivatives, slopes and diagrams. Nonlinear conditional derivatives are not labeled constant indices.

Logistic path products are statistical associations on the log-odds equation scale. They are not natural causal effects, probability differences or indirect-effect odds ratios. Observed-variable associations alone do not establish causation.

Install or upgrade

Extract the 0.2.2 release ZIP, close SPSS, and run PathLab-Setup.cmd once to add the calculation and plotting libraries to your own PathLab folder. SPSS supplies Python already. Choose Extensions → Install Local Extension Bundle, select PathLab-0.2.2.spe, and restart SPSS. Install the full .spe; a .spd alone supplies only the interface. Analysis never downloads packages or uploads data. See the release validation report for the builds and SPSS versions actually checked.
